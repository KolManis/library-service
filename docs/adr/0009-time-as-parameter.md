# ADR-0009. Время — параметром в домен, не `time.Now()` внутри агрегата

**Статус:** принято

## Контекст

Домен постоянно оперирует временем: `ReservationTTL` (бронь истекает через
3 дня), `LoanPeriodDays` (выдача на 14 дней), просрочка (`due_at` в
прошлом). Нужно решить, откуда методы вроде `Expire`/`MarkOverdue` берут
текущее время.

## Решение

Время всегда приходит **параметром**: `Issue(now time.Time)`,
`Expire(now time.Time)`, `MarkOverdue(now time.Time)`. Внутри домена нет ни
одного вызова `time.Now()`. Следствие для тестов: "время прошло"
моделируется данными (`reservedAt: now.Add(-4 * 24 * time.Hour)` —
бронь старше TTL), а не `time.Sleep`.

Это часть более широкого принципа "домен чист": приватные поля агрегатов,
единственная дверь для создания — конструктор (`Reserve`), никаких
gorm/json-тегов на доменных структурах (персистентная модель — отдельная
структура в адаптере, с явным маппингом), ошибки — sentinel-переменные
(`ErrInvalidTransition`, `ErrNotYetDue`) через `errors.Is`, а не сравнение
строк.

## Альтернативы

**`time.Now()` внутри методов домена.** Отклонено: тесты на граничные случаи
(бронь истекла ровно на 3 дня, штраф считается на конкретную дату) стали бы
либо недетерминированными (флаки от реального времени выполнения теста),
либо потребовали `time.Sleep` — медленно и хрупко. Пример уже упомянут в
`docs/style.md`/`loan_test.go`: `loanInStatus` заранее готовит `Loan` со
временем "как будто все пороги уже пройдены" — фиксированной датой
(`time.Date(2026, 7, 18, ...)`), без единого реального ожидания.

**Инжектировать интерфейс `Clock`/`TimeProvider` вместо голого параметра.**
Рассматривался как более "энтерпрайзный" паттерн, отклонён как избыточный
для этого масштаба: `func() time.Time` (см. сигнатуры `NewHandler(...,
now func() time.Time)` в командных хендлерах) даёт ровно то же самое —
подменяемый источник времени в тестах — без отдельного интерфейса и мока
под него.

## Последствия

- Каждый доменный метод, которому нужно "сейчас", явно объявляет это в
  сигнатуре — не нужно читать реализацию, чтобы понять, зависит ли метод от
  времени.
- Application-слой хранит `now func() time.Time` (обычно `time.Now` в
  проде, фиксированная функция в тестах) и передаёт результат вызова в
  доменные методы — источник времени один на весь сценарий вызова, не
  расходится между несколькими внутренними вызовами `time.Now()` в разных
  местах одной операции.
- Домен сам защищает свои временные инварианты (`Expire` проверяет TTL,
  `MarkOverdue` — что `due_at` прошёл) — правило не держится на том, что
  вызывающий код (воркер) не ошибётся и не дёрнет метод раньше срока.
